# Placitum json

[English](README.md) · Русский

Инспектор контракта API Placitum: сверяет вызов с описанием — OpenAPI 3.0/3.1 или отдельной JSON
Schema, что именно, выбирает профиль. Работает на обеих фазах, и фазы между собой не связаны:
операция находится по методу и пути, а они приходят в каждом сообщении. Сообщения WebSocket
тоже сверяются со схемами — в секции `frame` профиля.

Тело нужно целое. Префикс JSON невалиден всегда, поэтому усечённое тело инспектор не
валидирует вовсе, а решает по политике профиля: `on_truncated` — `deny` там, где непроверяемое не
проходит, `allow` там, где крупные тела законны.

```
модуль ──► waf.req.json ──►  json  ──► allow | deny | score
                               │
                               ├── тело и заголовки: из буфера по локатору
                               └── профиль: спека, политика исходов, запись в наборы
```

## Что здесь лежит

```
cmd/inspector/     шина, waf.req.json, обе фазы
cmd/probe/         проверка здоровья: профиль _probe отвечает deny без буфера
internal/schema/   компиляция OpenAPI и JSON Schema, поиск операции, находки
internal/validate/ порядок проверки: тело целое? разбирается? сходится?
internal/decide/   политика профиля → вердикт, чистая функция
internal/config/   окружение, inspector.conf, профили и горячая замена
internal/desired/  поколение из KV (policy/json), раскладка на диск
profiles/          default (выключен) и _probe
deploy/            Dockerfile
```

Сигнал активности, снимок машины, счётчики потока, уровни журнала и клиент справочника сетей — из
[`placitum-shared`](https://github.com/exemt/placitum-shared).

## Сборка

```sh
docker build -f deploy/Dockerfile -t placitum/json .
```

Что нужно рядом и все настройки — в [INSTALL.ru.md](INSTALL.ru.md).

## Профили

Профиль — это спека плюс политика: что делать с несовпадением, с усечённым телом, с операцией,
которой нет в описании. В образе два профиля. `default` выключен: проверять не против чего, пока
контроллер не доставит контракт; `_probe` служит проверке здоровья. Рабочие профили приходят
поколением из панели и подменяют каталог целиком; `_probe` подмешивается из образа.

Маршрут, чьего профиля нет, блокируется; на `default` инспектор не откатывается.
